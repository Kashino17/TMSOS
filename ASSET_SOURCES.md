# Asset sources

- `app/src/main/res/drawable-nodpi/ios27_default_dark.png`: Apple's static iOS 27 default dark wallpaper, published for wallpaper download by [9to5Mac, 10 June 2026](https://9to5mac.com/2026/06/10/download-the-new-ios-27-and-ipados-27-wallpapers-here/). [Original PNG](https://9to5mac.com/wp-content/uploads/sites/6/2026/06/iOS27_Default_Dark.png). Artwork belongs to Apple; no affiliation is implied. The file is stored unchanged.
- System icons are custom Canvas drawings in `IosSystemIcons.kt`, not extracted Apple app icons. Third-party icons come from the installed Android applications.
- Inter font files were already included in this project; they are used instead of SF Pro.

Visual references: [Apple iOS](https://www.apple.com/os/ios/) and [Apple Home Screen customization guide](https://support.apple.com/guide/iphone/customize-apps-and-widgets-on-the-home-screen-iph385473442/ios).
